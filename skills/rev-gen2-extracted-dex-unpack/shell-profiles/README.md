# 抽取型壳加解密档案

这里按**壳家族名称**存放已遇到的二代抽取型壳分析流程。每个文档重点记录容器、Native 变换、密钥查找和方法回填的可复用思路；样本哈希、密钥、RVA、段偏移、解密长度和测试日志留在各自工作区。

| 壳家族 | 已记录的变体 | 文档 |
|---|---|---|
| 梆梆加固 / Bangcle / SecNeo | `fdex` 容器中的抽取方法 | [bangcle-secneo.md](bangcle-secneo.md) |

新增壳时以家族名命名文件（如 `family-name.md`），同一家族的不同变体在文件内分节。**档案是分析线索，不是壳识别或算法证明**；先由 `rev-apk-shell-detect` 和当前 APK 的结构证据选择流程，再逐项核实档案中的假设。
